# Mira — visual Japanese vocabulary

Learn everyday Japanese words **inside a picture**, then reuse them in a short **dialogue**.

## How to use it

1. Open a **scene** (café, station, kitchen, convenience store, park).
2. Tap the glowing spots on the illustration to hear the word and see reading + meaning.
3. Switch to **Dialogue** and play each line — highlighted words match the same scene.
4. Open **Practice** for flip cards, listen-and-pick, and fill-in-the-blank lines.
5. **Review** lists every word, weakest first, using local progress on this device.

Speech uses your browser’s Japanese voice (`ja-JP`) when available.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
